Start at & size
  • Start at — the first sheet gets this number instead of 1, so a second file can continue where the first ended (e.g. 21, 22, 23…).
  • Total in "n / last" follows it too — start 21 with 10 sheets shows "21 / 30", not "21 / 10".
  • What it does — a dark page comes out as white paper with black ink, so a toner-heavy deck prints cheap and never soaks the sheet.
  • Pages become images — text is no longer selectable, but every sheet stays the exact same size and page count.
  • Off — the original vector PDF is packed untouched (sharpest text, but a dark page prints dark).
Raster quality
  • Resolution — scans render at 1× / 2× / 3× their own native sharpness (96 / 150 / 220 dpi); vector pages use the same pick.
  • Smooth edges — 2× supersampling with area-averaging (SSAA), so curves stay smooth instead of jagged.
  • Ink-bias curve — a γ=1.7 response gives inverted handwriting its full visual weight; thin strokes never break up.
  • Cost — higher dpi = cleaner print but a bigger file and slower run. 150 is the balanced default.
Colour style
  • Black ink — normal black & white. Edges stay smooth and soft.
  • Pure B&W — every dot is fully black or fully white, no grey at all. Best for handwriting.
  • Keep colours — coloured highlights stay coloured, just darkened so they print cleanly.
  • True negative — every colour flips to its opposite (blue → orange), like a photo negative.
  • White paper — paper is left exactly as it is; every colour and every dark mark becomes solid black ink. A dark area on the page (a blackboard panel, a dark slide) is flipped inside itself, so that board prints as white paper with black ink on it — the same as what a photo-negative tool does to it. This is the style for a page that is already white: Black ink and Pure B&W leave such a page untouched.
  • ON (default) — only dark pages are flipped; pages that are already white stay as they are.
  • OFF — every page is flipped, even light ones (light notes would turn dark — leave it ON unless you want that).

Printing tips
  • Print at Actual size / 100% (never “fit to page” — that re-scales and adds its own margins).
  • Single-sided is fine: each sheet already holds two note pages.
  • Dark board-notes print better on 90–120 gsm paper if your printer bleeds.

Questions students actually ask

Is my PDF uploaded anywhere?

No. The file is read by JavaScript in your browser (pdf-lib + pdf.js). There is no backend — not even an analytics ping with your filename. You can unplug the network after the page loads and it still works.

Will the text become blurry (images) after packing?

No. Each source page is embedded as a vector Form XObject, not a screenshot. Text stays selectable and prints at full printer resolution.

What if my page count is odd (401 pages)?

The last sheet gets one slide on top and clean white space below — handy for extra notes. Nothing is dropped or duplicated.

My notes aren't exactly 16:9.

The packer fits each page's own aspect into the full printable width, so 4:3, 16:10 or mixed decks also work. The middle gap simply adjusts to the leftover height.

Why not just print 2 slides per page from the PDF viewer?

Viewer “2-in-1” shrinks pages into half-height boxes with black borders and wastes the middle. Here the slides are re-laid-out flush at the edges with a purposeful note gap — and you get a real, shareable PDF file, not just one print job.

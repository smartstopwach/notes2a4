Start at & size
  • Start at — the first sheet gets this number instead of 1, so a second file can continue where the first ended (e.g. 21, 22, 23…).
  • Total in "n / last" follows it too — start 21 with 10 sheets shows "21 / 30", not "21 / 10".
  • What it does — a dark page comes out as white paper with black ink, so a toner-heavy deck prints cheap and never soaks the sheet.
  • Pages become images — text is no longer selectable, but every sheet stays the exact same size and page count.
  • Off — the original vector PDF is packed untouched (sharpest text, but a dark page prints dark).
Raster quality
  • Resolution — scans render at 1× / 2× / 3× their own native sharpness (96 / 150 / 220 dpi); vector pages use the same pick.
  • Smooth edges — 2× supersampling with area-averaging (SSAA), so curves stay smooth instead of jagged.
  • Ink-bias curve — a γ=1.7 response gives inverted handwriting its full visual weight; thin strokes never break up.
  • Cost — higher dpi = cleaner print but a bigger file and slower run. 150 is the balanced default.
Colour style
  • Black ink — normal black & white. Edges stay smooth and soft.
  • Pure B&W — every dot is fully black or fully white, no grey at all. Best for handwriting.
  • Keep colours — coloured highlights stay coloured, just darkened so they print cleanly.
  • True negative — every colour flips to its opposite (blue → orange), like a photo negative.
  • ON (default) — only dark pages are flipped; pages that are already white stay as they are.
  • OFF — every page is flipped, even light ones (light notes would turn dark — leave it ON unless you want that).

Printing tips
  • Printer will detect landscape automatically — print at Actual size / 100%, never “fit”.
  • Single-sided: each sheet already carries four note pages.
  • The 43 mm band survives double-sided too — band on both faces align at the same height.

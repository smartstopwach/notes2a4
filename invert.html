What happens to your file

1

The PDF is read locally in your tab (pdf.js). Your page count and every page's exact size are measured — nothing is re-flowed.

2

Each page is rendered at the dpi you pick and every pixel becomes 255 − value on all three channels — the true photographic negative of the page, alpha kept.

3

Pages are written back into a brand-new PDF with the same MediaBox sizes, same order, page 1 → page 1. Download it, print it, annotate it — it behaves like the original.

Printing tips
  • Print at Actual size / 100% — page dimensions are byte-identical to the original.

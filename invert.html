What happens to your file

1

The PDF is read locally in your tab (pdf.js). Your page count and every page's exact size are measured — nothing is re-flowed.

2

Each page is rendered at the dpi you pick and every pixel becomes 255 − value on all three channels — the true photographic negative of the page, alpha kept.

3

Pages are written back into a brand-new PDF with the same MediaBox sizes, same order, page 1 → page 1. Download it, print it, annotate it — it behaves like the original.

Output

Flip style
  • True negative — every colour flips to its opposite (blue → orange), like a photo negative.
  • Black ink — dark board becomes white paper with smooth edges; colours print as solid black.
  • Pure B&W — every dot is fully black or fully white, no grey at all.
  • White paper — paper is left exactly as it is; every colour and every dark mark becomes solid black ink. A dark area on the page (a blackboard panel, a dark slide) is flipped inside itself, so that board prints as white paper with black ink on it — the same as what a photo-negative tool does to it. This is the style for a page that is already white: Black ink and Pure B&W leave such a page untouched.
  • Light pages — pages that are already white pass through untouched; they are never flipped.
  • True negative · exact vector — the same 255 − c flip, but applied to the PDF itself: every pixel matches a dedicated inversion tool exactly, text stays text (sharp + selectable), the file stays small, and it finishes instantly (no rasterising, so Sharpness / Encoding do not apply).
  • Pure B&W · exact vector — every paint becomes solid black or paper white inside the PDF itself: text stays text, hairlines stay razor-sharp at 500% zoom, light pages pass through untouched (no rasterising, so Sharpness / Encoding do not apply; photos inside pass through).
Sharpness
  • 96 · fast — quickest, smallest file; fine for reading on screen.
  • 150 · balanced — sharp print without a heavy file.
  • 220 · max — the default; crispest lines and handwriting, biggest file and slowest run.
Encoding
  • PNG · lossless — the default; flat ink and text stay razor-crisp — best results, biggest file.
  • JPEG · smaller — much lighter file with a little softness around sharp edges.
  • Both — pages become full-page images, so text in the result is no longer selectable.
  • Never changes — page sizes and page count stay exactly as in your original PDF.
Packer layout — keep the white middle band white
  • Made for packer PDFs — each page's white middle band is detected and left white in every flip style (true negative, black ink, pure b&w, white paper) while the slides around it are converted.
  • Ruling moves into the band — enable Ruled lines below and the ruling draws only inside the white band.
  • Bandless pages flip fully — nothing is ever lost: only near-white rows are ever kept.
